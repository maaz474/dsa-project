# DSA Project

This repository contains a browser-based inventory management dashboard built using a singly linked list data structure.

## Features
- Inventory dashboard with KPIs
- Add, edit, delete, and search inventory items
- CSV import/export
- Linked list visualization and operations
- Activity log and dark mode

## Run locally
Open `index.html` in a browser.
